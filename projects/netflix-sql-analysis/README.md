# Netflix SQL Analysis

## Project Overview
This project analyzes Netflix data using SQL queries to extract insights about content, genres, countries, and yearly trends.

## Tools Used
- SQL
- PostgreSQL

## SQL Concepts Used
- GROUP BY
- Aggregate Functions
- Date Functions
- String Functions
- CTEs

## Key Insights
- Most common genres on Netflix
- Country-wise content distribution
- Yearly content trends
- Movies vs TV Shows analysis

## Files Included
- netflix_solution.sql → SQL queries
- README.md → Project documentation
- netflix datset
