# Walmart Sales Data Analysis

## Project Overview

This project demonstrates an end-to-end data analytics workflow using Python, PostgreSQL, and SQL. The Walmart sales dataset was cleaned and transformed using Python and Pandas, loaded into PostgreSQL, and analyzed using SQL queries to generate business insights.

## Tools & Technologies

- Python
- Pandas
- PostgreSQL
- SQL
- Jupyter Notebook
- VS Code
- GitHub

## Workflow

1. Loaded Walmart sales dataset into Python.
2. Performed data cleaning and preprocessing.
3. Handled missing values and data quality issues.
4. Exported cleaned data for database storage.
5. Loaded data into PostgreSQL.
6. Performed exploratory data analysis using SQL.
7. Generated business insights from the results.

## SQL Concepts Used

- GROUP BY
- Aggregate Functions
- Window Functions
- CTEs
- Date Functions
- Ranking Functions

## Key Insights

- Branch-wise sales performance
- Customer rating analysis
- Payment method trends
- Category-wise revenue analysis
- Sales patterns by day and time
